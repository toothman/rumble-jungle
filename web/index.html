Equalizer

Tap a band's frequency to fine-tune frequency and width (Q). The first band is a low shelf, the last a high shelf.

Rumble filter

Steep high-pass that removes subsonic noise from warped records and tonearm movement.

Auto headroom

Limiter

No clipping

Above −1 dBFS the signal is compressed smoothly instead of clipping hard. If this lights up often, lower the output gain or the input trim.

Automatic switching

In Auto mode the input that is playing stays on air until it goes silent. Then the other input takes over if it is playing. If both start together, the priority input wins.
